# 나래한글 뷰어 — 미완성 소스 보관

**상태: 미완성 / 실사용 비권장 / 추가 개발 중단 (2026-10-16)**

사용자 요청으로 현재 구현을 GitHub에 보관합니다. HWP/HWPX 전체 화면이 한컴과 쪽수·용지·RGB 픽셀 오차 0으로 같아야 한다는 목표를 달성하지 못했습니다. 완료 제품이나 실사용 검증 도구로 배포하는 것이 아닙니다. 일반 문서 읽기·출력 확인·나래엔진 검증의 기본 도구로 사용하지 않습니다.

읽기 전용 CLI, 화면 보기, 쪽별 텍스트, PDF·PNG 출력과 전체 쪽 비교 코드는 남겨 둡니다. 편집은 기존 나래한글 경로를 사용하며, 최종 문서 확인은 한컴 등 적절한 도구에서 합니다. 뷰어 스킬은 자동 선택을 끄고, 명시적인 소스 점검·실험 요청에만 사용하도록 바꿨습니다.

## 검증과 남은 차이

- 마지막 전체 검사는 **1/7문서·9/124쪽만 일치**했습니다. 실제 파일 7개·124쪽의 고정 한컴 기준 PDF를 유지합니다. 개인 문서·기준 PDF·글꼴·한컴 DLL·원시 REA 자료는 Git에 넣지 않습니다.
- 저장한 REA 관찰을 바탕으로 원형 그라데이션의 정수 반지름·홀짝 단계·중간 지점·색 보간과 32비트 프린터 좌표를 구현했습니다. 생략된 표 테두리의 반복 순서도 반영했습니다. 선형·원뿔형·사각형·다중 색·투명 그라데이션은 한컴 일치 검증이 끝나지 않은 대체 경로입니다.
- 회의록은 중간 확인에서 4쪽 중 3쪽이 같고 마지막 쪽 로마자 IV에 113픽셀 차이가 남습니다. HFT 굵은 글자 폭과 자간의 반올림 차이가 의심되지만 수정·검증을 마치지 않았습니다.
- PDF 투명도 점무늬의 프로세스 초기 위상, PNG 원본 알파와 효과 조합, 비트맵 굵기·기울임·밑줄, 복잡한 글꼴·줄바꿈·폭·셀 최소 너비 재배치 등에도 차이가 남습니다. 기존 신청서 본문 회귀도 해결된 것으로 간주하지 않습니다.
- 합성 표본이나 내부 처리 수는 실제 전체 문서 일치의 증거가 아닙니다. 마지막 전체 검사 결과와 과거 실패는 [검증 기록](validation.md), [검증 JSON](validation.json)을 함께 확인합니다.

## 재실행에 관한 주의

추가 개선이나 무차이 검증은 자동으로 이어서 실행하지 않습니다. 재개를 명시적으로 요청한 경우에만 조사합니다. 한컴 자동화가 필요한 실험은 한 번에 하나씩 실행하고, 직접 만든 프로세스의 신원·창·문서를 확인해 작업 뒤 종료합니다. 다른 작업의 한컴 문서는 종료하지 않습니다. 메모리 사용률 85% 이상 또는 여유 1.5 GB 이하에서는 새 묶음을 시작하지 않습니다.
