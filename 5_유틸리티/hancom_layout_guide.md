# 한컴오피스 조판 및 높이 계산 가이드라인

## 1. A4 용지 규격 및 본문 한계치
* 용지 크기: 210mm × 297mm
* 표준 여백: 위쪽 20mm, 아래쪽 15mm, 왼쪽 20mm, 오른쪽 20mm
* **본문 순수 가용 세로 높이**: `297mm - 35mm = 262mm`
* 안전 한계치: 머리말/꼬리말 및 문단 줄간격(160%) 누적을 감안하여 **240~250mm 이하**로 설계해야 다음 쪽으로 밀리지 않습니다.

## 2. 1쪽 표지 밀림 방지 공식
1쪽 표지에서 아래 항목들의 높이 합이 **160~180mm** 이내가 되도록 맞추면 한컴 2024에서 1쪽 안에 완벽하게 들어갑니다.

| 요소 구분 | 권장 수치 | 비고 |
| :--- | :--- | :--- |
| 상단 머리말 / 포인트 바 | 10 ~ 15mm | 높이 2mm 슬림 테이블 권장 |
| 빈 문단 여백 (before/after) | 12 ~ 18mm | 30mm 초과 금지 |
| 메인 제목 카드 표 | 36 ~ 42mm | 패딩 [8, 8, 6, 6] 적용 |
| 요약 정보 표 (4행) | 30 ~ 34mm | 행당 높이 7.5~8.5mm |
| 발행일 및 기관명 | 15 ~ 20mm | 폰트 12pt / 16~18pt |

## 3. 2열 무테이블 목차(TOC) 조판 트릭
일반 텍스트 점선(`········`) 대신 폭 140mm + 30mm의 2열 투명 테이블을 사용하면:
* 글자 폭과 상관없이 우측 페이지 번호(`1`, `2`, `3`...)가 수직으로 정렬됩니다.
* 행 높이는 10~11mm로 설정하면 7개 목차 항목이 75mm 안팎으로 2쪽 안에 정갈하게 수납됩니다.
